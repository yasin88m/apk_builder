# اپلیکیشن ساز — App Builder

استودیوی فارسی ساخت **وب‌اپ موبایلی قابل نصب (PWA)** برای معرفی کسب‌وکار؛ با الهام از پروژه `portfoilo_Builder` و چهار مرجع طراحی کاربر.

## امکانات نسخه ۱

- صفحه اصلی تیره و شیشه‌ای، درخشش بنفش و افکت نقطه‌ای محدود به Hero؛ تم روشن و رابط فارسی / انگلیسی.
- ویزارد چهارمرحله‌ای: کسب‌وکار، محتوا، ظاهر، انتشار.
- پیش‌نمایش واقعی موبایل با اسکرول مستقل و حالت تمام‌صفحه. تعویض مرحله، iframe را بازسازی نمی‌کند.
- چهار قالب: خدماتی Servly، آموزشی Eduboss، فروشگاهی Art Store، ورزشی Active؛ بازآفرینی با الهام از تصاویر مرجع، نه کپی تصاویر مرجع.
- نام، لوگو، بنر، معرفی، درباره ما، تلفن، ایمیل، آدرس، وب‌سایت و شبکه‌های اجتماعی.
- حداکثر ۳۰ محصول / خدمت / دوره با عنوان، دسته‌بندی، توضیح، قیمت و تصویر؛ افزودن، حذف و جابه‌جایی.
- فشرده‌سازی تصاویر در مرورگر، گالری اسلایدی ۱۲ تصویر، سه پلن و حداکثر پنج دیدگاه واقعی؛ کنترل نمایش بخش‌ها.
- پالت‌های هماهنگ و تنظیم مستقل رنگ اصلی، پس‌زمینه و نوشته‌ها؛ زبان مستقل اپ خروجی.
- ثبت‌نام و ورود واقعی، نشست HttpOnly، هش PBKDF2، محدودیت تلاش ورود، محافظت مبدأ درخواست و جداسازی مالکیت پروژه‌ها.
- پنل «اپ‌های من»: پروژه‌ها، وضعیت انتشار، ویرایش، حذف و تعداد بار بازشدن صفحه اصلی.
- انتشار با آدرس `/apps/my-business/`، به‌روزرسانی و لغو انتشار. پیش‌نویس از نسخه منتشرشده جداست.
- خروجی ZIP مستقل شامل HTML، ماژول‌ها، فونت محلی وزیر، تصاویر درون داده، آیکون‌های PNG ۱۹۲ و ۵۱۲، manifest و service worker.
- اپ خروجی: خانه، فهرست، جستجو، فیلتر دسته، جزئیات، علاقه‌مندی محلی و صفحه تماس؛ محتوای کش‌شده پس از اولین بارگذاری آفلاین در دسترس است.
- پنل `/admin` با محافظت سمت سرور؛ آمار واقعی کاربران، اپ‌ها، انتشار، بازدید و تعداد استفاده هر قالب.

## اجرای محلی

Node.js 22.13 یا جدیدتر لازم است. وابستگی npm برای اجرا وجود ندارد.

```sh
cp .env.example .env
npm start
```

آدرس پیش‌فرض: `http://localhost:3000`. مسیر داده‌ها `.data/` است و نباید داخل گیت قرار بگیرد. برای انتشار روی سرور Node، پوشه داده را روی فضای پایدار نگه دارید و HTTPS را از reverse proxy فراهم کنید. دسترسی به `.data` از وب مسدود است؛ فقط پوشه `public` سرو می‌شود.

## حساب مدیر

در محیط سرور مقدارهای `ADMIN_EMAIL` و `ADMIN_PASSWORD` را تنظیم کنید. رمز باید حداقل ۸ کاراکتر و قوی باشد. مدیر از همان صفحه ورود عادی وارد می‌شود. هیچ نام کاربری یا رمز عمومی پیش‌فرض وجود ندارد؛ ایمیل رزروشده مدیر با فرم ثبت‌نام قابل تصاحب نیست. اگر یک ایمیل از قبل کاربر عادی است، ایمیل مدیر دیگری انتخاب کنید؛ حساب عادی خودکار ارتقا نمی‌یابد. با حذف یا تغییر رمز محیط، ورود بعدی با رمز قبلی پذیرفته نمی‌شود؛ نشست‌های موجود تا انقضای هفت‌روزه باقی می‌مانند.

## خروجی و نصب روی گوشی

۱. در سامانه حساب بسازید، پروژه را ذخیره و با شناسه انگلیسی منتشر کنید.
۲. لینک اپ را روی گوشی باز کنید و از مرورگر پشتیبان «نصب برنامه / افزودن به صفحه اصلی» را بزنید.
۳. برای میزبانی مستقل، ZIP را دریافت، استخراج و **همه فایل‌ها** را روی HTTPS قرار دهید. مسیر زیرپوشه هم پشتیبانی می‌شود. بازکردن فایل با `file://` برای ماژول‌ها و نصب PWA کافی نیست.

**این نسخه APK تولید نمی‌کند.** خروجی PWA است. کاتالوگ و تماس فعال‌اند؛ پرداخت، سبد سفارش تجاری، پخش دوره، پیامک، حذف پس‌زمینه، اتصال دامنه خودکار و بازیابی رمز از طریق ایمیل به سرویس‌های جداگانه نیاز دارند و در نسخه فعلی پیاده نشده‌اند. دیدگاه‌ها واقعی‌سازی نمی‌شوند؛ صاحب کسب‌وکار باید متن مجاز خودش را وارد کند. نمونه‌ها برچسب نمایشی دارند.

## انتشار مستقل روی کلادفلر

آدرس عمومی سامانه: https://apk-builder.mohammadyasinmisaqpoor.workers.dev

این نسخه روی حساب Cloudflare مالک با Worker مستقل `apk-builder` و دیتابیس D1 اختصاصی `apk-builder-data` اجرا می‌شود و هیچ ورود یا سرویس اجرایی ChatGPT لازم ندارد. کد به‌صورت ماژول ESM از خروجی `npm run build` آپلود می‌شود؛ تنظیمات غیرمحرمانه در `deployment/cloudflare.json` ثبت شده‌اند.

خود سامانه نیز manifest، آیکون، سرویس‌ورکر و دکمه نصب دارد. نصب برنامه‌های ساخته‌شده باید از لینک عمومی هر اپ انجام شود، نه iframe پیش‌نمایش. دکمه نصب پنجره واقعی مرورگر را در صورت دریافت رویداد آماده‌بودن باز می‌کند؛ در مرورگرهای داخلی یا هنگام آماده‌نبودن، راهنمای واضح نمایش می‌دهد. خطاهای آماده‌سازی سرویس‌ورکر دیگر پنهان نمی‌شوند.

## ذخیره‌سازی و استقرار

- `server.mjs`: سرور مستقل Node و فایل‌های JSON پایدار با نوشتن اتمی و صف برای هر کلید.
- `src/api.mjs`: منطق مشترک مبتنی بر Request / Response، بدون وابستگی به Node.
- `src/store.mjs`: آداپتور D1 با queryهای پارامتری.
- `scripts/build.mjs`: تولید Worker ESM با دارایی‌های درون‌بسته در `dist/server/index.js`.
- `drizzle/0000_initial.sql`: جدول records؛ میزبان Sites مهاجرت را قبل از استقرار اعمال می‌کند.
- `.openai/hosting.json`: شناسه نسخه خصوصی قدیمی؛ برای انتشار عمومی Cloudflare و عملکرد سامانه استفاده نمی‌شود. فایل‌های خروجی و تمام مسیرهای اپ از دامنه فعلی استفاده می‌کنند.

پروژه عمداً هیچ Secret مربوط به پروژه پورتفولیو را کپی نکرده است. فونت وزیر از همان پروژه همراه مجوز فونت حفظ شده است.

## بررسی

```sh
npm run check
npm test
npm run build
```

تست‌ها SQLite واقعی را با شکل binding دیتابیس D1 اجرا می‌کنند و ورود، مالکیت، مدیر، انتشار مجزا از پیش‌نویس، برخورد آدرس، لغو انتشار، ZIP، اعتبار PNG و محدودیت ورود را پوشش می‌دهند.
