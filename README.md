# اپلیکیشن ساز — خروجی مستقیم APK

سامانه ساخت اپلیکیشن معرفی کسب‌وکار با **خروجی فایل APK امضاشده**، روی آدرس مستقل:

https://apk-builder.mohammadyasinmisaqpoor.workers.dev/

## مسیر کاربر

۱. ورود یا ثبت‌نام و ساخت پروژه.
۲. ثبت نام کسب‌وکار، نام مستقل اپلیکیشن، آیکون نصب، لوگو، معرفی، محصولات یا خدمات و راه‌های تماس.
۳. انتخاب یکی از چهار قالب خدماتی، آموزشی، فروشگاهی یا ورزشی و یکی از ۲۴ پالت هماهنگ یا رنگ‌های سفارشی.
۴. «ساخت و دانلود APK»: بسته‌بندی محتوا، اختصاص شناسه بسته، امضای برنامه و دانلود مستقیم فایل نصب.

خروجی APK، ZIP وب و انتشار وب‌اپ از مسیرهای حساب کاربری در دسترس هستند. ادیتور فریم نیز خروجی APK و ZIP ارائه می‌کند.


## ادیتور فریم و چیدمان

مسیر `/editor` محیط طراحی چندصفحه‌ای است. هر صفحه در `config.scene` یک درخت از لایه‌های مستقل دارد. سکشن‌ها از چیدمان آزاد، عمودی، افقی و گرید پشتیبانی می‌کنند. متن، تصویر، دکمه، ورودی، شکل، خط و آیکون از اجزای مستقل هستند؛ کارت‌ها و بنرهای آماده نیز به همین اجزا تبدیل می‌شوند.

- انتخاب چندتایی، کپی/چسباندن، گروه/بازکردن گروه، قفل، پنهان‌کردن و تغییر ترتیب لایه‌ها.
- اندازه بر حسب پیکسل یا پرکردن عرض والد؛ ارتفاع بر اساس محتوا یا ثابت؛ تغییر اندازه مستقیم و تنظیم X/Y در فریم آزاد.
- مدیریت صفحات، صفحه شروع و اتصال دکمه‌ها به صفحات دیگر.
- پروژه‌های قدیمی هنگام ورود به ادیتور به لایه‌های مستقل تبدیل می‌شوند؛ اطلاعات ذخیره‌شده قبلی تا ذخیره کاربر تغییر نمی‌کند.
- `scene.js` مدل، اعتبارسنجی و رندر مشترک ادیتور و خروجی است؛ `scene.css` و رندرر در APK و ZIP قرار می‌گیرند. ابزار ادیتور وارد اپ خروجی نمی‌شود.
- سقف پروژه ۲۰ صفحه و ۶۰۰ لایه، عمق تو در تو ۱۲، اندازه المان تا ۱۰٬۰۰۰ پیکسل و قلم تا ۵۱۲ پیکسل است.


### المان‌های تعاملی و موقعیت

کتابخانه و لایه‌ها در سمت راست و تنظیمات در سمت چپ نمایش داده می‌شوند. حالت‌های موقعیت خودکار، عادی، مطلق، ثابت و چسبان با اتصال به شش لبه و فاصله از چهار سمت پشتیبانی می‌شوند. منوی پایین از حالت ثابت به پایین نمایشگر استفاده می‌کند؛ چسبان رفتار CSS sticky داخل والد دارد. لایه‌های ثابت هنگام اجرا بیرون از والدهای چرخیده یا مقیاس‌خورده قرار می‌گیرند.

منوی همبرگری، منوی پایین، اسلایدر/اسلاید، هیرو و فرم از لایه‌های تو در تو ساخته می‌شوند. آیتم‌ها، اسلایدها، فیلدها و متن‌ها قابل انتخاب، تکثیر و ویرایش مستقل‌اند. اسلایدر فلش، نقطه، کشیدن لمسی و پخش خودکار قابل تنظیم دارد. فرم تکمیل اجباری و نوع فیلد را اعتبارسنجی می‌کند؛ پاسخ‌ها بنا به تنظیم سازنده روی دستگاه بازدیدکننده ذخیره می‌شوند یا پیش‌نویس ایمیل باز می‌شود. ارسال خودکار به سرور پیاده‌سازی نشده است. پیش‌نمایش فرم هیچ پاسخی ارسال یا ذخیره نمی‌کند.

## فایل اندروید

- اندروید ۷ (API 24) و بالاتر، با Android System WebView به‌روز.
- برنامه اندرویدی ترکیبی: یک Activity واقعی Java، نمایشگر داخلی WebView، فایل DEX، manifest باینری و منابع کامپایل‌شده اندروید.
- صفحات، تصاویر و فونت داخل APK هستند؛ اپ سایت خارجی را بارگذاری نمی‌کند و محتوای اصلی آفلاین باز می‌شود.
- برنامه مجوز اینترنت، دوربین، میکروفون، مخاطبین یا حافظه درخواست نمی‌کند. لینک‌های وب، تماس و ایمیل از طریق برنامه‌های مناسب دستگاه باز می‌شوند.
- هر پروژه یک شناسه بسته `ir.apkb.a<project-id>` و کلید RSA مستقل دارد. کلید و گواهی در ذخیره‌سازی خصوصی سرور می‌مانند و در API یا فایل خروجی افشا نمی‌شوند.
- نسخه‌های بعدی همان پروژه با همان کلید و شناسه، و کد نسخه مبتنی بر زمان ساخته می‌شوند. پروژه جدید یک اپ جداست. حذف پروژه، کلید آن و امکان ساخت به‌روزرسانی را نیز حذف می‌کند.
- امضای APK Signature Scheme v2؛ نام فارسی، شناسه و کد نسخه در manifest باینری تنظیم می‌شوند. فایل‌های ZIP برای Android resources به چهار بایت تراز می‌شوند.
- نام نصب از `appName` و در صورت خالی بودن از نام کسب‌وکار گرفته می‌شود. آیکون مستقل `appIcon` در مرورگر به PNG مربعی ۵۱۲ پیکسل تبدیل می‌شود. برای سازگاری با پروژه‌های قبلی، لوگوی PNG در نبود آیکون مستقل استفاده می‌شود.
- هر چهار قالب چیدمان، کارت، دسته‌بندی و جزئیات مخصوص دارند. دو قالب فروشگاهی سبد درخواست محلی دارند؛ پرداخت آنلاین و تکمیل خرید پیاده‌سازی نشده است.
- تصاویر نمونه فشرده و داخل APK هستند. منابع تصویر در `deployment/demo-media.md` ثبت شده است.
- هشدار ناشناخته بودن توسعه‌دهنده در Play Protect توسط گوگل تعیین می‌شود؛ امضای معتبر، نام و آیکون اختصاصی تأیید گوگل محسوب نمی‌شود. بررسی امضا و نبود مجوز حساس، تضمین حذف هشدار نیست. راهنمای رسمی: https://developers.google.com/android/play-protect/warning-dev-guidance

## ساخت موتور اندروید

Workflow `.github/workflows/android-runtime.yml` روی GitHub با Android SDK رسمی، Java را به DEX و منابع را با AAPT2 به APK پایه کامپایل می‌کند. فقط موتور عمومی و نمونه نمایشی در مخزن و artifact قرار می‌گیرند؛ محتوای کاربران و کلیدهایشان به GitHub ارسال نمی‌شود.

`public/android-runtime.json` شامل بسته کامپایل‌شده و SHA-256 آن است. API سرور این بسته را اعتبارسنجی می‌کند، محتوای پروژه را اضافه می‌کند، نام/شناسه/نسخه را تغییر می‌دهد و APK اختصاصی را با Web Crypto امضا می‌کند. بنابراین هر دانلود کاربر به اجرای دوباره Android SDK یا صف GitHub وابسته نیست.

Workflow، دو APK اولیه/به‌روزرسانی را با `apksigner` و `zipalign` بررسی می‌کند؛ آزمون شبیه‌ساز نصب، نمایش آفلاین و نصب نسخه بعدی را می‌آزماید.

## اجرای محلی

Node.js 22.13 یا جدیدتر لازم است؛ اجرای وب‌سایت وابستگی npm ندارد.

```sh
cp .env.example .env
npm start
```

فایل `public/android-runtime.json` باید از آخرین ساخت موفق موتور موجود باشد. اگر وجود نداشته باشد، سرور خطای واضح ۵۰۳ می‌دهد و فایل نصبی جعلی تحویل نمی‌دهد.

حساب مدیر از صفحه ورود عادی و با `ADMIN_EMAIL` و `ADMIN_PASSWORD` محیط سرور فعال می‌شود. رمز عمومی پیش‌فرض وجود ندارد. داده‌های Node در `.data/` نگهداری می‌شوند و در گیت قرار نمی‌گیرند.

## استقرار و داده‌ها

Cloudflare Worker مستقل `apk-builder` با دیتابیس D1 اختصاصی `apk-builder-data` اجرا می‌شود. تنظیمات غیرمحرمانه در `deployment/cloudflare.json` است. خروجی `npm run build` فایل ESM `dist/server/index.js` است و تمام دارایی‌های لازم را درون بسته دارد. برای حفاظت از هویت به‌روزرسانی اپ‌ها، از دیتابیس پایدار نسخه پشتیبان نگه دارید؛ هرگز کلیدهای امضای پروژه را داخل مخزن عمومی یا لاگ‌ها قرار ندهید.

## بررسی

```sh
npm run check
npm test
npm run build
```

تست‌ها ورود، جداسازی مالکیت، حذف خروجی وب، گواهی RSA، ساخت APK واقعی، فایل DEX، نام و شناسه در manifest، امضای v2، تراز منابع، حفظ امضای نسخه بعدی و رد موتور دستکاری‌شده را بررسی می‌کنند.

### SVG icons and editor shortcuts

The Persian RTL studio includes the official FREE line collection from `@untitledui/icons` 0.0.23 (1,173 icons). Use the **آیکون** element or select a button and open **انتخاب آیکون**. Search accepts English names and common Persian terms. Standalone icons scale with their layer; buttons expose size, stroke, gap, color and RTL before/after placement. The mobile interface and editor controls use the same family. Icons and `icons-NOTICE.txt` are included in hosted apps, ZIP exports, service-worker caches and offline APK assets. Provenance and the upstream licensing declarations are preserved in `public/icons-NOTICE.txt`.

Ctrl/Cmd+C and Ctrl/Cmd+V copy and paste selected root layers and their descendants using a bounded, normalized clipboard document. Text fields keep native clipboard behavior. Physical key codes also support Persian keyboard layouts. Hold Alt while dragging to duplicate once after crossing the drag threshold; releasing commits one undo step, and Escape or pointer cancellation restores the original scene. Alt-click alone creates no duplicate.
